# План реализации

1. Аудит и архитектура: репозиторий пуст, всё создаётся с нуля.
2. Финансовое ядро: схема БД, RLS, расчёты, валюты, тесты.
3. Веб-приложение: Overview, Transactions, Analytics, Debts, бюджеты и цели.
4. AI и Telegram: webhook, структурированный вывод (Zod), подтверждения, сводки.
5. Долги: avalanche/snowball, сценарии.
6. n8n, регулярные отчёты, безопасность, документация.

Принципы учёта: переводы между своими счетами и основная часть платежей по долгу не считаются доходом или расходом; для каждой операции хранятся исходная сумма, валюта, курс и дата курса; суммы считаются кодом или SQL, а не моделью.

Статус всех этапов — в README.
