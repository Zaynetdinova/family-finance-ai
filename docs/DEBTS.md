# Долги и план погашения

Код: `apps/web/src/lib/finance/payoff-plan.ts` (расчёт), `src/lib/debts/plan-load.ts` (данные), страница `/debts/plan`, ответ бота на «Как быстрее закрыть долги?».

## Модель расчёта

Каждый месяц, для всех долгов одной валюты:
1. Начисляются проценты: остаток × годовая ставка / 12 (округление до копейки).
2. Вносится минимальный платёж по каждому долгу (не больше остатка).
3. Дополнительная сумма + минимальные платежи уже закрытых долгов направляются по порядку стратегии:
   - **приоритетные** долги (отметка «Приоритетное обязательство») — первыми;
   - **лавина** — далее по убыванию ставки (минимальная переплата);
   - **снежный ком** — далее по возрастанию остатка (быстрее закрываются отдельные долги);
   - долги, где досрочное погашение запрещено, получают только минимальный платёж;
   - комиссия за досрочное погашение (если задана) уменьшает зачтённую сумму и учитывается отдельно.
4. Базовый сценарий «только минимальные» — без дополнительных денег и без перераспределения.

Результат: график по месяцам (платёж, проценты, остаток по каждому долгу), дата закрытия каждого долга, суммарные проценты и комиссии, сравнение сценариев и эффект дополнительного платежа («что если»).

Если платежей не хватает даже на проценты, план помечается как непогашаемый (горизонт 50 лет), а не показывает бесконечные числа.

## Сколько можно направлять на долги

Предлагаемая сумма = средний **свободный остаток** за последние до 3 полных месяцев в валюте долгов:
доходы − расходы (включая проценты) − погашение основного долга. Конвертация не используется.

- Если остатки на счетах меньше указанного минимального резерва — предложение 0: сначала резерв.
- Если истории нет — предложения нет, пользователь вводит сумму сам.
- Если введённая сумма больше среднего свободного остатка — предупреждение.

## Допущения (всегда показываются в плане)

- Проценты помесячно (банк может начислять по дням) → суммы приблизительные.
- Плавающая ставка считается по текущему значению.
- Неизвестная ставка → проценты 0; неизвестный минимальный платёж → 0. Оба случая явно перечисляются.
- Условия договора (досрочное погашение, комиссии, даты начисления) нужно сверять с банком.

## Тесты

`payoff-plan.test.ts`: порядок стратегий и приоритетов; совпадение с одиночной оценкой (`estimatePayoff`); точные числа первого месяца; закон сохранения денег (уплачено = остатки + проценты + комиссии); неотрицательные остатки; лавина не дороже снежного кома, обе лучше минимальных; перенос освободившихся платежей; эффект дополнительного платежа; запрет досрочного погашения; комиссия; непогашаемый долг; допущения; разные валюты; безопасная сумма с учётом резерва.
