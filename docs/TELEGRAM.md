# Telegram-бот и AI

## Как это устроено

```
Telegram ──webhook──▶ /api/telegram/webhook ──▶ handleUpdate()
                         │ проверка секрета        │ 1. update_id → telegram_updates (повтор = пропуск)
                         │                         │ 2. Telegram-пользователь → профиль (привязка по одноразовому коду)
                         │                         │ 3. OpenAI: только разбор текста/голоса/чека в JSON (Structured Outputs + Zod)
                         │                         │ 4. normalize.ts: валюта, счёт, категория, курс, разбивка долга — кодом
                         │                         │ 5. запись в transactions (confirmed или pending_confirmation)
                         │                         │ 6. ответ с кнопками: отменить / подтвердить / сменить категорию
```

- **Модель ничего не считает и не записывает сама.** Она возвращает поля из сообщения (сумма как текст, валюта как написано). Ответ проверяется Zod; невалидный ответ отбрасывается. Валюту, счёт, курс и суммы определяет код; запись делает сервер.
- **Неоднозначности → вопрос с кнопками**: «$», голое «песо» (если нет счёта в ARS), несколько счетов в валюте без счёта по умолчанию, перевод в другую валюту без суммы зачисления, неясная разбивка платежа по долгу.
- **Низкая уверенность, неизвестная категория, фото чека** → операция сохраняется как «ожидает подтверждения» и не попадает в отчёты, пока пользователь не нажмёт «Подтвердить».
- **Дубликаты**: повтор webhook отсекается по `update_id`; повторная запись того же сообщения — уникальным индексом `external_message_id = tg:<chat>:<message>`.
- **Права**: бот работает от серверного ключа, но каждый запрос ограничен бюджетом привязанного пользователя; наблюдатель (viewer) не может записывать; подтвердить/отменить операцию может только её автор.
- **Отчёты** (`/today`, `/week`, `/month`): все цифры считаются кодом (`src/lib/reports/build.ts`). Модель получает только готовые факты и пишет вывод и рекомендации; если в её тексте есть число, которого нет в фактах, текст отбрасывается и показываются правила-рекомендации из кода.
- **Вопросы** («Сколько потратили на продукты в сентябре?»): модель определяет тему и даты, ответ считает код (`src/lib/bot/questions.ts`).
- **Журнал**: каждое обращение к модели пишется в `ai_interactions` (статус, модель, токены, ошибка без секретов). Ограничение — 20 запросов на пользователя за 5 минут.
- **Голос** (до 2 минут, до 10 МБ) — распознаётся OpenAI и показывается пользователю перед разбором. **Фото чека** (до 5 МБ) — всегда требует подтверждения.

AI никогда не выполняет переводы, платежи и не меняет банковские счета: бот только ведёт учёт.

## Настройка

1. **Создайте бота**: в Telegram откройте @BotFather → `/newbot`. Сохраните токен и имя бота.
2. **Переменные** в `apps/web/.env.local` (и в окружении сервера при деплое):
   ```
   SUPABASE_SECRET_KEY=sb_secret_...          # Supabase → Project Settings → API Keys
   OPENAI_API_KEY=sk-...                       # новый ключ, не публикуйте его
   TELEGRAM_BOT_TOKEN=123456:ABC...
   TELEGRAM_BOT_USERNAME=my_family_finance_bot
   TELEGRAM_WEBHOOK_SECRET=<случайная строка 32+ символов из A-Z a-z 0-9 _ ->
   APP_URL=http://localhost:3000
   ```
   Секрет можно получить так: `openssl rand -hex 24`.
3. **Миграции**: `npx supabase db push` (нужна `0006_default_accounts.sql`).
4. **Привязка**: веб-приложение → Настройки → Telegram → «Получить ссылку» → откройте ссылку в Telegram и нажмите «Start». Там же выберите счёт по умолчанию для каждой валюты.

### Локальная проверка (без публичного адреса)

Webhook требует публичный HTTPS. Для разработки есть режим опроса: скрипт забирает обновления у Telegram и пересылает их в локальное приложение с тем же секретом.

```bash
cd apps/web
npm run dev                         # терминал 1
set -a; source .env.local; set +a   # терминал 2: загрузить переменные
npm run telegram:webhook delete     # webhook и опрос несовместимы
npm run telegram:poll               # пересылает обновления на http://localhost:3000
```

### Продакшен

После деплоя (адрес вида `https://...`):
```bash
APP_URL=https://ваш-адрес TELEGRAM_BOT_TOKEN=... TELEGRAM_WEBHOOK_SECRET=... npm run telegram:webhook set
npm run telegram:webhook info       # проверить: url, pending_update_count, last_error_message
```
Скрипт также регистрирует меню команд бота.

## Что проверить вручную

| Сообщение | Ожидание |
|---|---|
| `Потратила 8500 рублей на продукты в Магните` | ✅ Записано: Расход 8 500 ₽ · Продукты · Карта · дата · Магнит |
| `Получила зарплату 120 000 рублей` | Доход, категория «Зарплата» |
| `Заплатила 35 $ за ресторан` | Вопрос «доллары США или аргентинские песо?» с кнопками |
| `Купила кофе за 450 песо` | ARS, если есть счёт в ARS; иначе уточнение |
| `Перевела 20 000 рублей с накопительного счёта на карту` | Перевод без категории; доходы/расходы не меняются |
| `Вернули 1500 рублей за отменённый заказ` | Возврат: уменьшает расходы, не доход |
| `Заплатила 10 000 рублей по ипотеке, из них 4000 — проценты` | Основной долг 6 000, проценты 4 000; остаток долга −6 000 |
| Голосовое «потратила 300 рублей на кофе» | «Распознано: …», затем запись |
| Фото чека | «Проверьте операцию…» + «Подтвердить» |
| `Сколько мы потратили в этом месяце?` | Сумма расходов за месяц (совпадает с дашбордом) |
| `/month`, `/week`, `/today`, `/debts`, `/budget`, `/goals`, `/last` | Отчёты и списки |
| Повторная отправка того же сообщения (переслать) | Новая запись (это другое сообщение); повтор webhook — нет |

## Чем проверено

- 22 сквозных теста обработчика (`src/lib/bot/handler.test.ts`) с подставными Telegram, хранилищем и OpenAI: привязка, права, все примеры операций из ТЗ, уточнения кнопками и текстом, подтверждение только автором, отмена и смена категории, невалидный ответ модели, ограничение запросов, голос, чек, команды, вопросы.
- Тесты клиента OpenAI (строгая схема, отказ модели, ошибки сети/HTTP, ключ не попадает в тело запроса), клиента Telegram, построителя отчётов и проверки чисел в AI-тексте.
- SQL-тесты RLS для `default_accounts`.
- **Живая проверка**: выполнена владельцем проекта на реальном Supabase с OpenAI, бот запущен локально в режиме опроса (`npm run telegram:poll`). Работа через публичный webhook после деплоя ещё не проверялась.
- Модель по умолчанию `gpt-4o-mini` (меняется через `OPENAI_MODEL`); она должна поддерживать Structured Outputs и изображения.
